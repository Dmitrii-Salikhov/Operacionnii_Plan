# Windows smoke (v1.1.6)

Чеклист после CI-артефакта `PlanOperaciy-Windows` / релиза zip:

1. Распаковать zip на чистую папку.
2. Скопировать рабочие `calendars.json`, `credentials.json`, `token.pickle` (или пройти мастер).
3. Запустить `PlanOperaciy.exe` — UI тёмный, bridge `ok`.
4. **Календари…** — видны ID; при необходимости сохранить.
5. **Неделя** — календарь-выбор; после загрузки счётчики по ID и строки в журнале.
6. **Сформировать** — шаги парсинг → распределение → Excel; файл создаётся.
7. Опция «Список поступлений» — второй xlsx рядом.
8. **Обновления** — проверка GitHub; при новой версии на Windows кнопка «Скачать и установить».
9. Убедиться, что после обновления secrets на месте (см. MIGRATION.md).

Реальные данные календаря в CI не гоняем (нужны секреты) — этот smoke ручной на машине клиники/разработчика.
